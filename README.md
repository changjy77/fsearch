# 🔍 fsearch - Windows 파일 검색 도구

![Version](https://img.shields.io/badge/version-1.1.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Python](https://img.shields.io/badge/python-3.12-blue)
![Platform](https://img.shields.io/badge/platform-Windows-blue)

**빠르고 강력한 Windows 파일 검색 프로그램**

파일명과 파일 내용을 동시에 빠르게 검색하고, 원클릭으로 파일을 실행할 수 있는 PyQt5 기반의 데스크톱 애플리케이션입니다.

---

## ✨ 주요 기능

### 🔍 고급 검색
| 기능 | 설명 |
|------|------|
| **파일명 검색** | 빠른 파일명 검색 (와일드카드 지원) |
| **내용 검색** | 파일 내용에서 검색어 찾기 |
| **정규식** | 복잡한 패턴 검색 (예: `.*\.(doc\|docx)`) |
| **실시간 검색** | 검색 중 실시간 결과 표시 |
| **검색 제어** | 언제든지 검색 중단 가능 |

### ⚡ 성능 최적화
- **멀티스레드**: 기본 16개 스레드 (1~32 조정 가능)
- **대용량 파일 스킵**: 10MB 이상 자동 제외
- **메모리 캐싱**: 검색 결과 캐싱으로 빠른 재검색
- **평균 검색 속도**: 약 수초 (크기/스레드/파일 형식에 따라 다름)

### 📂 폴더 관리
- **폴더 제외**: 검색에서 제외할 폴더 설정 (AppData, Program Files 등)
- **최근 경로**: 자주 검색하는 경로 저장 (최대 5개)
- **제외 통계**: 자주 제외하는 폴더 자동 기록 (최대 5개)

### 📊 검색 결과
| 컬럼 | 내용 |
|------|------|
| **파일명** | 검색어 붉은색 강조 표시 |
| **경로** | 전체 파일 경로 |
| **크기** | B, KB, MB 단위 자동 변환 |
| **수정 날짜** | 마지막 수정 날짜/시간 |
| **검색 단어수** | 파일 내 검색어 출현 횟수 |

### 📁 지원 파일 형식
- **문서**: Word (.doc, .docx), PowerPoint (.ppt, .pptx), PDF (.pdf)
- **텍스트**: 텍스트 (.txt), 마크다운 (.md), HTML (.html, .htm)
- **한글**: 한글 (.hwp, .hwpx)
- **스프레드시트**: Excel (.xls, .xlsx)
- **데이터**: CSV (.csv), JSON (.json), XML (.xml)
- **압축파일**: ZIP (.zip) — 내부 문서까지 풀어서 검색

### 🚀 편의 기능
- **빠른 실행**: 결과 더블클릭으로 파일/폴더 열기
- **검색 이력**: 최근 검색 키워드 10개 저장
- **성능 측정**: 검색 소요 시간 표시
- **자동 로깅**: 홈 디렉토리의 `.fsearch/logs` 폴더에 저장
- **대용량파일 로그**: 스킵된 파일 목록 확인 가능

## 📥 설치 및 사용

### 🎯 방법 1: 실행 파일 (권장 - 가장 간단함)

**단계별 설치:**
1. `dist/fsearch.exe` 다운로드
2. 원하는 폴더에 저장
3. 더블클릭으로 실행

**장점:**
- Python 설치 불필요
- 바로 사용 가능
- 어디서나 실행 가능

### 💻 방법 2: 소스코드 실행 (개발자용)

**설치:**
```bash
# 1. 저장소 복제
git clone https://github.com/changjy77/fsearch.git
cd fsearch

# 2. 필수 라이브러리 설치
pip install PyQt5 python-docx PyPDF2 openpyxl python-pptx

# 3. 실행
python fsearch_gui.py
```

**장점:**
- 소스코드 수정 가능
- 최신 버전 사용
- 커스터마이징 가능

## 🎯 사용 방법

### 기본 사용 예시

```
1️⃣ 검색 폴더 선택
   - "📁 폴더 선택" 버튼으로 검색할 폴더 지정
   - 기본값: C:\Users\username

2️⃣ 검색어 입력
   - 파일명 검색: "report"
   - 내용 검색: 파일 내에 포함된 텍스트

3️⃣ 검색 옵션 선택 (필요시)
   - "파일명만": 파일명에서만 검색
   - "내용만": 파일 내용에서만 검색
   - "정규식": 정규표현식 사용
   - "대용량파일 스킵": 10MB+ 파일 제외

4️⃣ "🔍 검색" 버튼 클릭
   - 진행 상태는 진행바로 확인
   - 검색 중단: "⏹️ 중지" 버튼

5️⃣ 결과 확인
   - 테이블 탭: 구조화된 결과 표시
   - 텍스트 탭: 상세 정보 표시
   - 파일 더블클릭으로 즉시 열기
```

### 실전 예제

**예제 1: Word 문서에서 "회의록" 검색**
```
폴더: C:\Users\username\Documents
검색어: 회의록
옵션: 내용만 체크
결과: 모든 Word 문서에서 "회의록"이 포함된 파일 목록
```

**예제 2: 특정 확장자 파일 찾기 (정규식)**
```
폴더: C:\
검색어: \.exe$
옵션: 정규식 체크, 파일명만 체크
결과: 모든 .exe 파일 목록
```

**예제 3: 대용량 파일 제외하고 검색**
```
폴더: D:\
검색어: backup
옵션: 대용량파일 스킵 체크 (10MB 제외)
결과: 빠른 검색 완료
```

### 고급 옵션

| 옵션 | 용도 | 예시 |
|------|------|------|
| **파일명만** | 파일명에서만 검색 | "2024" → 2024 파일명만 |
| **내용만** | 파일 내용에서만 검색 | 문서 내 특정 텍스트 |
| **정규식** | 복잡한 패턴 검색 | `^test.*\.pdf$` |
| **대용량파일 스킵** | 10MB 이상 제외 | 빠른 검색 |
| **폴더 제외** | 특정 폴더 검색 제외 | AppData, Temp 등 제외 |

## 🔧 개발 정보

### 기술 스택
- **언어**: Python 3.12
- **GUI**: PyQt5 (5.15.9+)
- **멀티스레드**: ThreadPoolExecutor (기본 16개)
- **파일 처리**:
  - python-docx (Word 문서)
  - PyPDF2 (PDF)
  - openpyxl (Excel)
  - zipfile (한글 .hwp/.hwpx)

### 프로젝트 구조
```
fsearch/
├── fsearch_gui.py          # 메인 프로그램 (~1650줄)
├── README.md               # 사용 설명서
├── .gitignore              # Git 무시 파일
└── dist/
    └── fsearch.exe         # 배포용 실행 파일 (49MB)
```

### 주요 클래스
- **SearchWorker**: QThread 기반 검색 엔진
- **SearchHistory**: 검색 이력 및 설정 관리
- **FSearchGUI**: 메인 UI 윈도우

### 핵심 기능
- **검색 엔진**: ThreadPoolExecutor로 병렬 파일 검색
- **파일 처리**: 7+ 파일 형식 지원 (Word, PDF, Excel, 한글, 텍스트 등)
- **UI/UX**: PyQt5 탭 인터페이스 (테이블/텍스트 결과)
- **검색 결과 강조**: 검색어를 붉은색으로 표시
- **파일 실행**: 검색 중/완료 상관없이 더블클릭으로 즉시 실행

## 🐛 트러블슈팅

### Q: 파일이 실행되지 않습니다
**A**: 다음을 확인하세요:
- fsearch.exe가 손상되지 않았는지 확인
- Windows Defender에서 차단되지 않았는지 확인
- 관리자 권한으로 실행 시도
- 파일이 실제로 존재하는지 확인 (네트워크 경로는 지원 불가)

### Q: 검색이 느립니다
**A**: 다음을 시도하세요:
- 대용량파일 스킵 체크 활성화
- 스레드 수 증가 (기본 16 → 32)
- 검색 폴더 범위 축소
- 불필요한 폴더 제외 (AppData, Temp 등)

### Q: 특정 파일 형식이 검색되지 않습니다
**A**: 지원 형식 확인:
- 문서: .doc, .docx, .pdf, .txt, .md
- 스프레드시트: .xls, .xlsx
- 한글: .hwp, .hwpx
- 웹: .html, .htm

### Q: 로그 파일은 어디에 있나요?
**A**: `C:\Users\<username>\.fsearch\logs\` 폴더 확인

### Q: 검색 중에 파일을 실행할 수 있나요?
**A**: ✅ 가능합니다! 검색이 진행 중일 때도 테이블에서 파일을 더블클릭하면 즉시 실행됩니다.
